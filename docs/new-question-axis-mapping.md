# 60 题版与八维坐标关联报告

日期：2026-11-13

测试版本：`2026-11-13.1`

本版以 60 道题、8 个坐标轴替换原有 47 题版。完整题干、数组下标和逐题权重见 [`question-axis-weight-list.md`](./question-axis-weight-list.md)。

## 本版结构

- 题目分为财政问题、社会制度、税收、政治制度、民族文化、地缘外交、扩展题组、性别议题和公共政策九个分组，共 60 题。
- 八个轴为：政府规模、经济分配、社会文化取向、政治制度、民族文化、外交军事、国际取向、性别立场。
- 原来的“社会价值”和“文化取向”合并为“社会文化取向”，轴代码统一为 `social`；旧 `culture` 轴删除。
- 新增“性别立场”，轴代码为 `gender`。
- 同一设备在 `2026-11-13.1` 版本可以再次提交一次；旧版本结果保留，不会被迁移或覆盖。

由于题目、题号、轴名称和计分权重均发生变化，本版数据不能与旧版按同一题号或同一百分点直接合并比较。分析时应先按 `test_version` 分组。特别是性别轴已从“传统性别角色—性别平等”改为“利男—利女”，旧版性别轴百分比不能直接换算或合并。

## 计分方向

回答选项值为：`很支持 = 2`、`一般支持 = 1`、`中立 = 0`、`一般不支持 = -1`、`很不支持 = -2`。每题对某轴的贡献等于“选项值 × 该轴权重”；若该题被标记为“非常重要”，权重再乘以 `1.5`。

本版不再使用反转标记。权重直接带方向：

- **正权重**：支持该题时推向轴的右侧。
- **负权重**：支持该题时推向轴的左侧。
- 某轴百分比为正时靠近右侧端点，为负时靠近左侧端点，0 表示该轴的中立位置。

| 维度 | 左侧 | 右侧 |
| --- | --- | --- |
| 政府规模 `government` | 小政府 | 大政府 |
| 经济分配 `income` | 偏高收入 | 偏低收入 |
| 社会文化取向 `social` | 社会文化保守 | 社会文化开放 |
| 政治制度 `political` | 权力集中 | 政治开放 |
| 民族文化 `han` | 多元民族文化 | 汉民族文化 |
| 外交军事 `peace` | 武力主义 | 和平主义 |
| 国际取向 `west` | 反欧美中心 | 亲欧美 |
| 性别立场 `gender` | 利男 | 利女 |

## 重要题加成

- 每道题都有一个可切换的“我觉得非常重要”按钮。用户标记后，前端把该题记为 `true`，提交时通过 `importantQuestions` 数组发送；数组长度必须为 60，元素只能是布尔值。
- 被标记题目的所有轴权重都乘以 `1.5`，包括该题原本关联的每个轴；不会改变轴的左右方向。
- 计算百分比时，分母中该题的最大可能贡献也同步乘以 `1.5`，因此八轴百分比仍保持在 `-100..100`。重要题在轴内获得更高相对权重，但不会被错误地算到范围之外。
- 服务端不信任客户端分数，会使用原始答案和 `importantQuestions` 重新计算；数据库字段为 `importance_json`，保存 60 个布尔值。
- CSV 中 `importance_count` 是标记题数；`important_q01` 至 `important_q60` 是该题是否被标记的 `0/1` 列。

## 重点方向校准

### 民族文化

- 第 21、22、30、60 题在支持时推向右侧“汉民族文化”，权重分别为 `+3`、`+2`、`+1`、`+2`。
- 第 8 题“身份证上划分各民族”和第 23 题“保护少数民族文化语言专项政策”在支持时推向左侧“多元民族文化”，权重分别为 `-1.5` 和 `-1.5`。
- 旧版曾依赖反转字段表达这一方向；本版改为直接使用带符号权重，避免页面显示与分数方向不一致。
- 本版将右侧端点改为“汉民族文化”，与左侧“多元民族文化”构成新的端点表达；民族文化轴的题目与权重不变。

### 外交军事

- 第 26 题“维持台海现状、不以武力解决”在支持时推向右侧“和平主义”，权重为 `+2`。
- 第 27 至 30 题涉及支持外国入侵、军事进攻或恢复失地，在支持时均推向左侧“武力主义”，权重为 `-2`、`-2`、`-2`、`-1`。
- 因此该轴的正负号现在与“和平主义在右、武力主义在左”的界面标签一致。

### 国际取向

- 第 24、25、26、28、57 题在支持时推向右侧“亲欧美”，权重为 `+1`、`+0.5`、`+2`、`+1`、`+2`。
- 第 27、29、30 题在支持时推向左侧“反欧美中心”，权重为 `-2`、`-2`、`-0.5`。
- 第 28 题“支持美国进攻伊朗”在本测试的既有轴定义下按亲美西方方向编码；这一题同时以 `-2` 推向武力主义一侧，两个轴并不矛盾。

### 性别立场

- 正百分比表示更靠近右侧“利女”，负百分比表示更靠近左侧“利男”。
- 第 45、46、48、51 题在支持时推向右侧“利女”，权重为 `+2`、`+3`、`+1`、`+1`。
- 第 49、50 题在支持时推向左侧“利男”，权重为 `-0.5`、`-1`。
- 第 46 题“男方承担主要彩礼和婚礼费用”在本版按支持时更有利于女方家庭的方向编码，因此从旧版 `-3` 调整为 `+3`。
- 第 49 题“对男性受害者提供同等法律保护”在本版按支持时更有利于男性的方向编码，因此从旧版 `+0.5` 调整为 `-0.5`。
- 第 47 题的育儿假按本版权重表只计入社会文化取向和政府规模，未额外添加性别轴贡献。

### 社会文化取向

- 原来的社会价值题和文化取向题统一计入 `social`，因此本轴的题目覆盖从旧版两个较窄的轴合并而来。
- 第 6、16、24、25、35、36、47、49、53、57 题等支持时推向开放一侧；第 7、19、42、46 题等支持时推向保守一侧。
- 合并后该轴题量增加，但旧版社会价值分数和文化取向分数不能直接换算为本版 `social` 分数。

| 轴 | 涉及题数 | 绝对权重合计 | 说明 |
| --- | ---: | ---: | --- |

## 数据解码与分析建议

- 服务端使用 `questionnaire.js` 对 60 个原始答案和 `importantQuestions` 重新计分，不信任客户端上传的分数。
- `answers_json` 的数组下标 `0—59` 对应第 1—60 题，选项编码为 `0—4`；对应关系见权重总表。
- `importance_json` 的数组下标与题目一一对应，`true` 表示该题按 `1.5` 倍权重计算，`false` 表示使用基础权重。
- `scores_json` 和 `percentages_json` 的轴键为 `government`、`income`、`social`、`political`、`han`、`peace`、`west`、`gender`。
- CSV 包含 `q01` 至 `q60`、`important_q01` 至 `important_q60`、`importance_count`，以及八轴分数和百分比；本版不再输出 `culture`。
- 分析旧记录时，旧 `culture` 字段仍只存在于旧版本 JSON 中；新版记录不会生成该字段。不要把新旧版本的百分比当作同一量表直接做均值比较。
- 新版权重属于初步内容效度权重，正式使用前应结合项目目标、预测试结果和区分度分析复核。

## 解释性限制

- 部分题目同时测量两个以上概念。例如第 28 题同时涉及外交军事和国际取向，第 46 题同时涉及性别立场和社会文化保守，结果解释不能只看单题。
- 第 41 题合并了无偿对外援助和可能亏损的对外援建，二者不再分开计分。
- 性别立场只有 6 题，极端分数更容易受单题影响；报告该轴时应同时给出题数和样本量。
- “利男/利女”是对政策受益方向的简化编码，不等同于对性别平等的完整规范判断；部分题目可能存在多种解释，分析时应同时参考原始答案。
- 本报告描述的是题库设计与计分映射，不对题目立场作规范性评价。
